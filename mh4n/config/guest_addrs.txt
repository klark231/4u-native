# the game, at the USA v1.3.0 update's addresses. When a code mod replaces the whole code.bin with
# another build of the game (Heavenfall), functions and variables are not where they are in the
# update: tools/guest_map.py finds where each one is, and the library carries the pairs
# (rc_guest_from / rc_guest_to) for the app to look up (mh4n/guest_addr.h).

#   <address>  fn|data  <name>
#
